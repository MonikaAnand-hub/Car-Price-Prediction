# Car Price Prediction Using Machine Learning

## 1. Project Introduction

The Car Price Prediction project aims to predict the selling price of a used car using machine learning techniques.

The project uses car-related features such as present price, kilometres driven, car age, fuel type, seller type, transmission, and number of previous owners to estimate the selling price.

Two machine learning algorithms, Linear Regression and Random Forest Regressor, are implemented and compared to identify a suitable model for price prediction.

## 2. Project Objectives

- To analyze used car data and understand the factors affecting car prices.
- To clean and preprocess the dataset.
- To select relevant features for prediction.
- To train machine learning regression models.
- To evaluate model performance using MAE, RMSE, and R² score.
- To predict the selling price of a car using its features.
- To compare the performance of different machine learning models.

## 7. Model Evaluation Metrics

The models were evaluated using the following metrics:

- **MAE (Mean Absolute Error):** Measures the average absolute difference between actual and predicted prices.
- **RMSE (Root Mean Squared Error):** Measures prediction error while giving more weight to larger errors.
- **R² Score:** Indicates how well the model explains variations in the target variable.

Lower MAE and RMSE values generally indicate better predictions, while a higher R² score generally indicates a better fit.

## 8. Results and Insights

### Model Performance

The performance of Linear Regression and Random Forest Regressor was evaluated using the test dataset.

| Evaluation Metric | Linear Regression | Random Forest |
|---|---:|---:|
| MAE | 1.472892 | 1.516455 |
| RMSE | 2.524035 | 3.653683 |
| R² Score | 0.752815 | 0.482045 |

### Best Model

Based on the evaluation results, **Linear Regression performed better than Random Forest Regressor** on the test dataset.

Linear Regression achieved a lower MAE of 1.472892 and a lower RMSE of 2.524035. It also achieved a higher R² score of 0.752815.

The Random Forest model achieved an MAE of 1.516455, an RMSE of 3.653683, and an R² score of 0.482045.

Therefore, Linear Regression was selected as the best-performing model from the two models tested.

### Key Findings

- Linear Regression performed better than Random Forest Regressor on the test dataset.
- The Linear Regression model explained approximately 75.28% of the variation in selling prices, based on its test R² score.
- The model's prediction errors indicate that there is still room for improvement.
- Data preprocessing and appropriate feature selection are important for building an effective prediction model.

**Note:** The MAE and RMSE values are expressed in the same units as the target variable. Their interpretation depends on the price unit used in the dataset.
